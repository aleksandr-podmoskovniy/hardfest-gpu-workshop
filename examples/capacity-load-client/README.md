# Клиент для новых проверок вместимости

Отправляет независимые длинные запросы одновременно и проверяет фактическое
число выходных токенов. Это синтетическая нагрузка, не оценка качества чата.

HTTP-перенаправления и системный HTTP proxy отключены. Клиент проверяет адрес
ответа, чтобы запрос незаметно не попал на другой сервис. Адрес endpoint
сохраняется только в приватном отчёте: перед публикацией он удаляется.
Запросы метрик используют тот же транспорт.

Клиент предназначен для Linux и закрытого HTTP endpoint подготовленного
runtime. У него нет персональной авторизации — не отключайте защиту публичного
API ради теста. Для проверки AI Inference endpoint должен принадлежать заказу
InferenceService; сам HTTP обслуживает vLLM.

Параметры запуска и проверка результатов — в
[описании тяжёлой нагрузки RTX](../../results/rtx5060-heavy/README.md#повторить-и-проверить).

[Старая версия](../pro6000-load-client/) сохранена неизменной для воспроизводимости
уже опубликованных измерений. Наличие новой защиты не меняет статус старых
результатов; точная версия клиента определяется хешами в каждом отчёте.
