# Статус доказательств

Это не live health-check. Сводка исходных артефактов подготовки, перенесённая при создании учебника.

| Что | Статус | Чего это не доказывает |
| --- | --- | --- |
| Шесть моделей в старом hardfest-demo | Проверены materialization, headers/offsets/index references файлов | Полные hashes всех весов и правильность inference |
| Gemma + assistant | Файлы готовы, профили перенесены | Успешные 256K, speculation и speedup |
| Qwen TP2 | Файлы и runtime image подготовлены | CUDA/NVLink, вместимость и 50 одновременных сессий |
| Runtime vLLM 0.30.0 | Digest закреплён, существовал проверенный mirror | Совместимость всех комбинаций backend/quant/cache |
| H100-нода | В последнем эксплуатационном отчёте был аппаратный/Ready gate | Не разрешение снять cordon или перезапустить ноду |
| Динамический MIG/MPS | Есть опыт другого стенда и реальный DRA-контракт | Проверку на выбранной A100 этой площадки |
| Deckhouse UI/CRD | Известны подготовленные версии из старого контура | Полное соответствие формы текущему runtime |

Полный объём safetensors шести моделей: **199515799962 байта (~185,81 GiB)**. Это не объём RAM/VRAM и не свободная S3 quota. Перед продолжением проверить storage заново: не создавать второй комплект PVC только ради учебника.

Исходная презентация опиралась на GPT-OSS/EAGLE3. Практические упражнения используют Gemma/assistant и Qwen TP2. Формулы GPT-OSS сохранены как отдельная учебная задача; они не являются планом памяти Gemma. Старые performance-цифры не используются как результаты новых запусков.

## Условия подтверждённого запуска

1. Получить свежие Ready/CUDA/DRA/NVLink свидетельства, не меняя чужую нагрузку без согласования.
2. Прогнать A/B на одинаковом рабочем окне и зафиксировать эффективные defaults.
3. Доказать CPU reload, не только GPU prefix reuse.
4. Проверить assistant с этой версией runtime и реальные токены принятия.
5. Экспортировать проверенную форму сервиса Deckhouse.
6. Подтвердить model API, геометрию и освобождение MIG/MPS, включая корректность метрик.
7. Выполнить упражнения и заполнить [чек-лист проверки](REHEARSAL.md).

Все performance-таблицы пока остаются пустыми. Даты и результаты старых RTX-экспериментов не служат замером H100.
