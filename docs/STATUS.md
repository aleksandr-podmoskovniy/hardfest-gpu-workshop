# Готовность примеров

Полный прогон упражнений на H100 пока не завершён. Здесь собраны результаты подготовки файлов и конфигураций; состояние кластера нужно проверить перед запуском.

| Компонент | Что проверено | Что ещё нужно проверить |
| --- | --- | --- |
| Шесть моделей | Наличие файлов, заголовки, смещения тензоров и ссылки в индексах | Контрольные суммы всех весов и ответы моделей |
| Gemma и assistant | Файлы и профили запуска подготовлены | Работу с контекстом 256K, черновую генерацию и производительность |
| Qwen TP2 | Файлы и образ vLLM подготовлены | CUDA, связь между GPU, вместимость и допустимое число одновременных запросов |
| vLLM 0.30.0 | Образ закреплён по digest | Совместимость выбранных способов вычисления, квантования и кэширования |
| Нода с H100 | Последний отчёт указывает на проблемы оборудования или состояния Ready | Текущее состояние ноды и доступ к CUDA; восстановление согласуется отдельно |
| Динамический MIG и MPS | Проверены на другом стенде, известен интерфейс DRA-драйвера | Создание разделов и совместную работу сервисов на A100 этой площадки |
| Console и CRD Deckhouse | Сохранены сведения о версиях модулей исходного стенда | Соответствие формы создания сервиса установленной версии движка |

Файлы safetensors шести моделей занимают 199515799962 байта, около 185,81 GiB. Объём памяти для запуска считается отдельно. Перед загрузкой проверьте свободное место в хранилище и существующие PVC, чтобы не создавать лишние копии.

Расчёт памяти GPT-OSS в теоретической части — отдельный пример. Практические упражнения используют Gemma с assistant и Qwen TP2, для которых нужны собственные замеры.

## Что осталось сделать

1. Проверить Ready, CUDA, DRA и связь между GPU, не затрагивая чужие задачи.
2. Выполнить A/B с одинаковым контекстом и сохранить фактические параметры vLLM.
3. Проверить по метрикам выгрузку KV в RAM и обратную загрузку на GPU.
4. Запустить assistant и измерить долю принятых токенов.
5. Проверить создание сервиса в Deckhouse и сохранить его манифест.
6. Проверить API эмбеддера и реранкера, создание и освобождение MIG-разделов, совместную работу через MPS и показания метрик.
7. Пройти [проверку стенда](REHEARSAL.md).
