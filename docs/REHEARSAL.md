# Проверка окружения и результатов

## Перед запуском

- [ ] Согласованы владелец стенда, окно работ, rollback и границы чужой нагрузки.
- [ ] Ноды Ready, нет неизвестного cordon, обе H100 доступны CUDA через DRA.
- [ ] Записаны GPU SKU/VRAM, driver, module/CRD/runtime versions, топология и результат NCCL-проверки.
- [ ] GPUClass/GPUPool selectors не захватывают соседние карты; DeviceClass созданы контроллером.
- [ ] Все PVC Bound, пути и revisions моделей подтверждены, места и квот хватает.
- [ ] Runtime доступен на нодах, image pull credentials настроены.
- [ ] VPN/SSO и kubeconfig работают; секреты не выводятся в логи и скриншоты.
- [ ] Read-only preflight указывает на ожидаемый API/context.
- [ ] Явно выбраны stages, которые будут запускаться; чужие workloads не затрагиваются.

## Для воспроизводимых измерений

- [ ] Измерены время загрузки и компиляции; они отделены от времени запросов.
- [ ] Для A/B одинаковы рабочее окно, model/tokenizer revisions, dataset SHA, sampling и precision весов.
- [ ] Claims выделены на разных физических H100; нет конкурирующей нагрузки.
- [ ] Выполнены smoke и проверки правильности ответов.
- [ ] Cold/repeat/decode серии повторены минимум три раза, сохранены raw результаты.
- [ ] Перед каждой серией зафиксировано состояние кэша; повтор не назван холодным запросом.
- [ ] Queue, prefill и TTFT подписаны с правильной агрегацией.
- [ ] CPU reload подтверждён после GPU eviction; иначе результат отмечен неподтверждённым.
- [ ] Для assistant проверены качество, acceptance и итоговая скорость.
- [ ] Для платформенного сервиса сверены план, effective args, claim и ответ API.
- [ ] Для MPS подтверждены общий MIG instance, квоты, ответы embedding/reranking и корректность метрик.
- [ ] Для TP2 отдельно подтверждены совместимость модели/runtime, топология и фактическая вместимость.

Пять CLI-команд могут потребовать продолжительной загрузки или компиляции. Дождитесь готовности API; таймаут команды не означает ни успешного запуска, ни автоматического удаления ресурсов. Сохраните логи и используйте [диагностику](TROUBLESHOOTING.md).

## После упражнений

- [ ] Остановлены только созданные hf-* Deployment через `stop <stage> --ack`.
- [ ] Созданный `hf-platform-gemma` удалён отдельно через Console.
- [ ] Pod/claims освобождены, проверено состояние геометрии и доступной ёмкости.
- [ ] Namespace, PVC, модели и GPUClass/GPUPool сохранены.
- [ ] При необходимости исходная нагрузка восстановлена по согласованному rollback.
- [ ] Отчёт заполнен; перед публикацией удалены credentials и приватные данные.
