# 1. Gemma A/B на двух H100

Запустим две копии Gemma на разных H100 одного узла и сравним их на одинаковых запросах. Перед началом [подготовьте площадку](../docs/SETUP.md): обе карты должны быть свободны, файлы моделей — доступны локально.

## Запуск реплик

```bash
python3 scripts/hf.py apply a --ack
python3 scripts/hf.py apply b-tuned --ack
python3 scripts/hf.py start a --ack
python3 scripts/hf.py start b-tuned --ack
python3 scripts/hf.py get resourceclaims
python3 scripts/hf.py logs a
python3 scripts/hf.py logs b-tuned
```

DRA должен назначить разные физические устройства. Сверьте идентификаторы в назначениях ResourceClaim и UUID, которые видит CUDA внутри контейнеров. Вывод `nvidia-smi` на узле не показывает, какая карта доступна каждому контейнеру.

Сохраните из логов фактическую конфигурацию, формат и ёмкость KV-кэша, вычислительную реализацию, сведения о компиляции и захвате графов, доступную память. Выполните короткий пробный запрос к каждой реплике. HTTP 200 на `/health` недостаточно: сервис должен сгенерировать ответ.

## Запросы к двум сервисам

```bash
python3 scripts/hf.py port-forward a 18001
# В другом терминале:
python3 scripts/hf.py port-forward b-tuned 18002
```

В третьем терминале выполните серии из [методики измерений](../docs/MEASUREMENTS.md). Реплики используют CPU и память одного узла, поэтому нагружайте их последовательно: сначала A, затем B, потом в обратном порядке. Одновременные прогоны будут влиять друг на друга.

## Если 256K не поместилось

Сохраните ошибку запуска и бюджет памяти. Уменьшите `context_tokens` в `.local/site.json` до общего для обеих реплик значения, остановите оба Deployment и повторите `apply` и `start`. Не добавляйте выгрузку весов в RAM. Скорость сравнивается при одинаковом окне; предельную вместимость каждого профиля измеряйте отдельно.

## Условия сравнения

- Учитываются все ошибки, в том числе нехватка памяти.
- Версии моделей, SHA запросов и параметры генерации совпадают.
- Длина входа подтверждена полем `usage` сервера.
- Префиксы холодной серии различаются; шлюз не возвращает готовые ответы из своего кэша.
- Если в исходном профиле уже работали CUDA graphs, chunked prefill или префиксный кэш, в сравнении они отмечены как включённые.

После измерений остановите реплики. Модели и общие PVC сохранятся.

```bash
python3 scripts/hf.py stop a --ack
python3 scripts/hf.py stop b-tuned --ack
```
