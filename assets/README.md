# Иллюстрации

`workshop-qr.svg` — QR-код на [главную страницу воркшопа](https://github.com/aleksandr-podmoskovniy/hardfest-gpu-workshop). Встроен в начало README, хранится локально в Git, не использует внешние сервисы изображений. Чёрный код на белом фоне, защитное поле 4 модуля, коррекция Q; создан Segno 1.6.6. После смены адреса репозитория нужно перегенерировать QR и проверить декодирование самого SVG.

Картинки добавляются после реальной репетиции, без нарисованных «успешных» статусов.

План кадров:

1. Две H100 и отдельная A100: роли карт, без внутренних IP/UUID при публикации.
2. Одинаковый A/B workload и раздельные queue/prefill/TTFT графики.
3. GPU KV / CPU-tier: подтверждённый store → eviction → reload.
4. Speculation: acceptance и скорость рядом, а не один процент.
5. Console: выбор модели, профиль, план, claim, работающий API.
6. MIG до/после claims; два MPS-клиента на одном instance, разные квоты.
7. Освобождение геометрии после scale-to-zero.
8. TP2 topology и реальная нагрузочная кривая, если подтверждена.

Формат: PNG/SVG, имена `01-topology.png`, `02-ab-timing.png` и т. п. Под каждым кадром — подпись с условиями и alt text. Скриншоты не должны показывать токены, SSO-коды, browser account, чужие namespace или приватные endpoints. Не добавлять тяжёлые видео и PPTX в Git: отдельные release assets после согласования.
