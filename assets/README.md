# Иллюстрации

`workshop-qr.svg` — QR-код на [главную страницу воркшопа](https://github.com/aleksandr-podmoskovniy/hardfest-gpu-workshop). Встроен в начало README, хранится локально в Git, не использует внешние сервисы изображений. Чёрный код на белом фоне, защитное поле 4 модуля, коррекция Q; создан Segno 1.6.6. После смены адреса репозитория нужно перегенерировать QR и проверить декодирование самого SVG.

Схемы используют синий и бирюзовый цвета исходной презентации. Это редактируемые SVG с текстом, без внешних шрифтов, скриптов и изображений. Их можно открыть отдельно или увеличить прямо из README.

Пересобрать схемы после редактирования исходника:

```bash
python3 scripts/build_diagrams.py
```

Схемы не подменяют результаты: условные размеры и целевые конфигурации подписаны. Готовность реального стенда отражена в [STATUS.md](../docs/STATUS.md), измерения публикуются только вместе с условиями. Для будущих скриншотов нужно скрыть токены, коды входа, аккаунты, чужие namespace и приватные адреса. Тяжёлые видео и исходная презентация не входят в Git.
