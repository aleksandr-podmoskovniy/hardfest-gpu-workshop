# Персональный доступ участников

Статус: разработка; этот файл не подтверждает развёртывание. Тариф и бюджет
согласованы, но ещё не включены как персональная политика для участников.

На проверенном Bifrost `v2.0.38-d8-edition` создание временного VK через API
управления вернуло HTTP 500. Ошибка повторилась без бюджета, без лимита
частоты и без разрешённых провайдеров. Список ключей читается, оба provider key
Gemma существуют, созданных проверочных VK в повторном чтении списка нет.
Работающее подключение Open WebUI поэтому пока не переключалось.

Локальный прототип проверяет подпись, актуальную роль, запрет MCP, ограничение
параллельности и передачу SSE: 22 теста проходят с `go test -race`.
Это не заменяет проверки в установленном Bifrost и не является готовой
инструкцией развёртывания. Прототип не включён в публичный путь установки.

Open WebUI остаётся источником учётных записей и решений администратора.
Внутренний адаптер проверяет подписанный JWT пользователя, повторно проверяет
его роль через API Open WebUI и подставляет личный Virtual Key Bifrost.
API управления Bifrost используется только для ресурсов с собственной меткой.
OIDC-подключение и OAuth/MCP ведущего не переключаются на этот адаптер.

Тариф демонстрационный, без списания денег: вход $10/млн токенов,
выход $20/млн токенов, бюджет $500 на 24 часа. Расход не сбрасывается
при повторном входе, рестарте адаптера или повторном одобрении.

На первом этапе один экземпляр адаптера: это не HA-компонент. Добавлять
реплики без распределённой блокировки выпуска ключей нельзя.
Личные VK никогда не возвращаются браузеру. Подпись пользователя и
межсервисный ключ — разные секреты; неподписанные заголовки не принимаются.

Сценарии проверки до переключения подключения:

- [ ] `pending-user-denied`: pending не получает действующий VK и ответ модели.
- [ ] `approved-user-provisioned`: одобрение выпускает один VK с нужными правами.
- [ ] `reconcile-preserves-spend`: повторная сверка и вход сохраняют ключ и расход.
- [ ] `blocked-user-revoked`: новая работа блокируется, VK выключается.
- [ ] `forged-identity-denied`: подпись, issuer, срок, sub и актуальная роль проверяются.
- [ ] `participant-mcp-denied`: MCP и произвольные provider/model/key не проходят.
- [ ] `per-user-usage-recorded`: два пользователя имеют раздельные токены и стоимость.
- [ ] `budget-and-rate-denied`: исчерпание отдельного тестового бюджета/лимита даёт отказ.
- [ ] `stream-and-audio-preserved`: SSE и голос работают через тот же личный ключ.
- [ ] `oidc-presenter-preserved`: отдельное OIDC-подключение не изменено.

При ошибке API, неполном списке пользователей или неоднозначном VK доступ
закрывается; чужие ключи не исправляются. Проверочные пользователи и ключи
удаляются отдельно от реальных участников. История и документы сохраняются.
